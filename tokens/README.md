# Artes dos tokens

Coloque os PNGs nesta pasta com os nomes listados em `catalogo.js`. Use nomes de arquivo com a mesma grafia, inclusive maiúsculas e minúsculas.

As cinco naves aliadas usam os nomes `nave-aliada-1.png` a `nave-aliada-5.png`. As cinco inimigas usam `nave-inimiga-1.png` a `nave-inimiga-5.png`. As demais artes usam `vida-5.png`, `vida-1.png`, `escudo.png`, `overwatch.png`, `dano.png`, `energia.png` e `calor.png`.

Para usar outro nome ou acrescentar uma arte, edite `catalogo.js`. Por exemplo, `{ type: 'nave', file: 'ranger.png', label: 'Ranger' }`. Recarregue a página depois de publicar as artes. Use zero cópias para omitir um token da impressão.

Recorte a arte perto do seu contorno antes de salvar o PNG. A escala usa o retângulo da imagem inteira, incluindo qualquer margem transparente.
